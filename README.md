# SuperSophie

SuperSophie 是一个 Markdown-first、离线优先的智能工作空间：块笔记、Notion 风格数据库、多 Agent 协作、代码编辑、多模型路由、社交连接器与跨设备云同步被放进同一套可移植的数据模型。

当前首版包含：

- Markdown 块编辑器与 `.sophie` 离线包导入/导出
- 11 种数据库视图与任务交互
- 多 Agent 工作台和多模型路由界面
- 代码编辑工作台
- 微信、QQ、Telegram、OneDrive 与 App Cloud 连接器面板
- D1 文档索引、R2 附件存储和 IndexedDB 离线副本

产品基线见 `docs/PRODUCT_SPEC.md`，架构与同步协议见 `docs/ARCHITECTURE.md`。
